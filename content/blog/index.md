## About This Blog

This blog uses a **Content-as-Code** approach where all articles are written in Markdown, validated automatically, and published through CI/CD pipelines.

### Article Structure

Each article includes:
- **TL;DR** summary for busy readers
- **Live playground links** for interactive examples
- **Implementation guides** with step-by-step instructions
- **Real-world applications** from Evolution framework

### Publishing Workflow

1. **Write** articles in `drafts/` using templates
2. **Validate** with automated checks (frontmatter, links, code compilation)
3. **Publish** using `bin/publish-article.ps1` script
4. **Deploy** automatically via GitHub Actions
